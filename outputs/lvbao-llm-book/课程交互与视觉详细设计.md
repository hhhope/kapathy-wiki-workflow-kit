# LLM ATLAS 课程交互与视觉详细设计

本文是实施与验收依据。范围包括首页、14 节主线、深入阅读、扩展课、16 个旧专题、独立图示和视频入口。旧版「统一天气例子」约定由本文的分组案例替代。来源、代码、公式和旧链接继续保留。本文记录设计，页面实现与实测结果另记在 validation/interaction-coverage.json。

## 修复优先级

1. 先修样式。验收原视频收起时是否还有留白、正文与控件字体是否一致、面板是否套层、第7课旧内联 SVG 是否仍混用浅色样式。用第2、5、7、14课做桌面与手机前后对照。
2. 再修例子。逐项处理用户点名的 ID、向量匹配、Attention、多头、Transformer 三站、KV Cache、梯度路径、规模与 RAG。每个案例先确认读者能说出要观察什么，再补公式与动效。

## 共用界面与状态

- 标准面板按问题、操作、图形、核对结果排列。正文只有一层面板外框。局部节点可以有轮廓，禁止在实验外再套同款卡片。
- 中文统一用系统无衬线字体，优先 PingFang SC、Microsoft YaHei，SVG 继承同一字体。正文 16–17px，标题 24–32px，控件和图注至少 14px，公式与对齐数字用等宽字。行高正文 1.75，控件 1.4。面板内边距桌面 24px、手机 16px；控件最小高度 44px。
- 沿用深色 Atlas。背景 #0d1223，主文字 #edf0ff，次级文字 #bac4dd，紫色表示当前选择，青色表示新算或新增，琥珀表示待核验。文字标签、图形轮廓同时承担状态提示。正误与警告均配文字。验收时检查普通文字对比度至少 4.5:1。
- 默认状态给出预测题和输入。一次操作只改一个条件，保留对照信息。选择、图形、数值和结论取自同一状态。计算细节折叠；重置恢复初始值及选中状态。独立大图复用节点和说明，先展示结构，再允许逐节点查看。
- 动画规格：控件反馈 120ms，数值条与位置过渡 220ms，路径或新增节点突出 280ms。位置变化保留前后参照，连接线只在依赖确实改变时改向。重绘不抢焦点。减少动态效果下立即切换，保留文字、轮廓和选中状态；手动导览仍可用。自动导览由用户启动，可暂停，离开视口或切换标签页后停止。
- 移动端按相同顺序堆叠，控件可换行，宽图和宽表仅在各自容器内部滚动。支持 Tab、Enter、Space；同组节点支持方向键与 Home/End；结果区用非打断式播报。
- 原视频位于主实验与核对之后，默认仅一行标题、对应问题和外链，无 iframe 占位。展开后才挂载播放器，桌面宽度上限 240px，手机不超过容器，保留竖屏比例。收起停止播放。失败时外链仍在。时间点仅在已核实后显示。

| 12 规模、蒸馏、涌现 | 三张独立实验桌 | 规模：固定预算，用教学近似 C∝ND 比较参数/数据配比，预算条不变；蒸馏：同一猫图硬标签100/0/0与教师70/20/10，概率条过渡；涌现：固定一道四步题和三个模型的输出，逐项完成数分别2/3/4，切逐项与全对指标 | 同预算不决定唯一配比；软标签携带类间信号；同一输出可在指标切换时呈渐变或跳变，不能据此判断所有涌现 |

第3课点积续例采用固定方向的贡献对照：小周音乐、电影为 2、3，小林为 7、9。两项权重分别为 [1,0] 与 [1,2]，分数从 2/7 变为 8/25。相似距离留作另一道对照题。OpenAI 拓展参考 <https://openai.com/index/extracting-concepts-from-gpt-4/>；规模参考 <https://arxiv.org/abs/2203.15556>；蒸馏参考 <https://arxiv.org/abs/1503.02531>；幻觉参考 <https://arxiv.org/abs/2509.04664>。研究数据与教学设定分开标明。

第11、13、14课共享一套虚构资料：旧规则限额600元；2026-07-01生效的现行规则限额800元、须有效凭证；单据日期2026-07-15、金额680元。工具返回有效时只能说满足演示列出的两项条件；查询无结果表示未知，不等同于凭证无效。

## 深入阅读、扩展与旧入口

- 深入页保留论文、推导、原视频与代码，勾连回主课相同名词和输入。参加对照的实验都有默认值、调参、记录基线、结果和重置。第4/5/6/7课分别看分布、注意力加权、头贡献、矩阵形状；第9/10/11/12/13/14课分别核对损失、更新、早停、KL、代理评分、证据适用性。参照结论必须与实际公式一致。
- 扩展09强化学习：移动机器人，显示第三步奖励10与第一步折扣回报8.1。扩展11遗忘：切换删除记录前后，模型影响状态仍保留。扩展12 CLIP：切图后重排匹配行。扩展13卷积：移动高亮窗口，显示乘加结果 −1→2。扩展14贝叶斯：筛证据，分母100→24，后验16/24。扩展15自训练：切换是否人工核验，显示错误置信度变化。六课均提供操作后核对和对应深入链接。
- 旧章01–16依次保留神经元、余弦、损失、梯度/Adam、早停/Dropout、注意力、温度、蒸馏、折扣、奖励、EWC、对比学习、卷积、贝叶斯、乘法增长、检索计算。进入后可回相应主课或扩展，旧路径继续有效。来源与视频索引只保留检索、定位和跳转，使用紧凑列表。
- 37 个独立图示按用途处理：16 张专题图突出概念节点，16 张路线图突出数据流，decoder/block/qkv 逐层核对依赖，softmax/vector 查数字与形状。原图端点、箭头方向、节点说明和嵌入页版本逐项比对，避免箭头标签被误归为节点内容。支持正文展开大图，并可从浏览器返回原阅读位置。

## 概念何时出现

- 幻觉第1课先认识：逐词生成能写出流畅句子，也可能生成错误事实。用一句能当场核对的错答示例，先给读者识别标准。第5课厘清注意力权重与事实依据的边界，第13课展示怎样的评分会鼓励猜测，第14课做完整查证。
- 过拟合第9课先认识：训练样本上的损失降了，还要拿没见过的样本试一次。第10课区分优化路径和泛化结果，第11课用训练与验证曲线完整演示选检查点。第13课再对照奖励投机，两个现象分别验收。

## 实施顺序与证据

1. 先完成视频、字体、面板和第7课内联 SVG 的样式修复，再实现第2、5、14课的案例样板。验收答案分别是「相邻ID不等于相似」「同一前文取到不同信息」「找出无效引用与缺失凭证」。
2. 样板通过后，按第3/6、7/8、9/10、11/13、12的关系落地，再覆盖首页、深入阅读、扩展、旧章和独立图。
3. 每页记录初始状态、操作步骤、预期输出、实际输出、手机与桌面证据。测试键盘操作、减少动效、重置和视频折叠/失败外链。旧锚点和本地资源另行扫描。按钮可点与宽度通过只代表基本功能，仍须核对教学结论和图文一致性。

## 替换难懂例子的实际题面

以下题面优先于前表的简写。首屏先给情境、问题和一个操作。核对区显示观察结果，公式可在需要时展开。

| 替换哪一课 | 读者看到并亲手操作的例子 | 操作后可核对的结果 |
|---|---|---|
| 02 ID 和向量 | 「你是17号。想找人一起听歌看电影，选18号还是900号？」先选，再翻开两张兴趣卡。 | 图上先出现号码，翻卡后出现音乐/电影坐标。你(8,8)，18号(2,3)，900号(7,9)。高亮900号，显示两个坐标分别只差1。再切到模型查表，先看到编号，再看到这行的数字。 |
| 03 点积 | 沿用上课，换成「你在替社团选本周活动搭档。只看音乐和只看电影，会选同一个人吗？」加入小陈，音乐9、电影2。按钮只改推荐规则。 | 对比小陈(9,2)和小林(7,9)。只看音乐时9对7，小陈领先；只看电影时2对9，小林领先。随后展开乘加：权重[1,0]或[0,1]，按维度列贡献。这里比较对活动要求的评分，相似距离仍留在第2课。 |
| 05 Attention | 「小明把书递给小红，因为她要读书。」点「她指谁？」或「递了什么？」 | 句子位置固定，改问法时连线在小红和书之间切换。先说“把哪条线索带到当前位置”，再展开权重和加权求和。指代和权重是教学设定，不能凭权重判断回答真假。 |
| 06 多头 | 还是递书。看同一句话的两个教学通道。打开人物通道时看见「小红」，打开物品通道时看见「书」。 | 点拼接，两个通道并排保留；点投影，看两路的数如何共同影响同一输出。公式层沿用[2]和[3]，先拼成[2,3]，再按[1,2]混合得到8。 |
| 07 Transformer | 「小红翻开一本，模型怎么把‘书’列成候选？」重做旧三站图，三个节点沿固定主路可点。 | 点输入看文字切片、查表；点加工看「一本」所在位置的表示结合前文；点候选看词表分数。词还没选定，避免把候选分数画成已经生成的答案。 |
| 08 KV Cache | 用课7的前缀，推进一轮把「书」加到句末。屏幕并列两套处理，只有是否使用缓存不同。 | 两侧都用同一前缀算出同样的下一轮教学结果。一侧每层重算四个位置的K/V，另一侧读旧三组、只新算「书」的一组。新位置的查询仍连到旧三组。 |
| 09–10 梯度 | 账单12元，想靠调单价把估价调准。第9课先点5元左右的小变化；第10课固定起点，再切步长。 | 5→5.01时损失4→3.9204，先看方向，再展开−8。相同斜率下，步长.125落到6元，步长.5越过目标落到9元。另开局部低点画面解释脚下的坡无法说明远处哪里更低。 |
| 12 规模、蒸馏、涌现 | 分三次操作：同预算下挪动参数和数据配比；同一张猫图切正确标签和教师概率；同一组四步题结果切逐步和整题评分。 | 预算保持100；教师分布额外显示狗比车更像；模型完成2/3/4步，逐步得50/75/100%，整题得0/0/100%。三张图分别解释预算、监督信息和指标，避免共用一条模糊结论。 |
| 14 RAG 与证据 | 「680元差旅能不能报？」先点一条带第9条引用的错答，再打开制度和工具结果。 | 第9条不存在。旧制度600元但已失效，现行800元且要求凭证。查询有效时可确认满足这两项；无结果时只能确认金额符合、凭证待查。点击结论能回到对应证据。 |

样式改动先用「同一题面、同一屏」做前后对照。视频收起后正文可连续阅读；正文、选项、图注统一中文字体；第7课只有一层图示面板。样式验过后再换案例，避免把换文案和视觉修复算成同一次验收。

## 过拟合：熟题拿满分，换个问法还会吗？

第9课在损失下降后插入一道对照题：「这笔680元能不能报？」与「我这趟出差花了六百八，票据还没核验，能直接提交吗？」两题使用同一条现行规则和同一笔单据，标准答案都是「金额符合限额，凭证仍待核验」。让读者先看到同一模型在熟悉题上答对、在未见改写上漏掉凭证条件，再问训练损失下降能否保证换题也答对。单题对照引出问题，第11课用多题结果判断。

第11课固定两批题：20 道训练题和 20 道未参与训练的验证题。所有数量为教学设定，评分项为是否同时答对限额和凭证状态。第5轮训练 16/20、验证 14/20；第10轮训练 19/20、验证 12/20。读者先猜保留哪个检查点，再在同一面板切轮次，两根条和正确题数一起更新；点「查看错题」展开上面那对问法。按本例的验证结果保留第5轮；独立测试集留到选完之后。图上直接标出：训练多答对3道，验证反而少答对2道。第13课才更换评分规则，这里全过程保持评分标准不变。

## 全站视觉与动效验收

视觉沿用首页的深底、紫蓝光感和实验面板。正文、图注、按钮、表格、图内中文共用字体与字号层级；公式、参数和数值共用等宽字体与数字对齐方式。页面可以使用不同图形，但同类按钮、滑块、选中状态、圆角与间距使用同一组件。内嵌 SVG 与独立图共用同一套颜色和字体，移除图里的旧浅底和局部硬编码字体。选中态必须同时有颜色、形状或文字变化。

| 交互类型 | 主动效 | 同步更新 |
|---|---|---|
| 查表和向量对照 | 保持坐标尺不动，兴趣卡揭示后落到坐标点，细光线连到相近点 | 卡片数据显示与点位一致，选中项写清楚 |
| Attention、多头与 Transformer | 选中节点亮起，连接线改向；两路节点合到一个拼接区，再由投影线汇入输出 | 权重、贡献、选中步骤与结果同步 |
| 逐词生成与缓存 | 新 token 从候选滑到句尾；新增 K/V 块亮青色，复用块保留位置和标签 | 句尾、下一轮输入、复用数和新算数同时更新 |
| 梯度、早停与模型对照 | 固定坐标和比例，落点沿路径出现；切检查点时两根结果条同尺度过渡 | 当前步长、预测值、损失或验证结果同步 |
| RAG 与幻觉核验 | 点击回答中的一句，沿连线打开对应证据；缺证据处用琥珀框和标签标出 | 条款、工具状态和可确认范围同时对应 |

每轮只突出一个主要变化，文字、图注和控制区位置保持稳定。动效时长采用前述 120/220/280ms 规格，首页背景动效与实验图区分。关闭动效后，状态、路径和结论仍可完整操作和阅读。

样式先行验收：在同一题面上截取桌面和 390px 手机画面，对照第2课、Attention、第7课、RAG 与独立大图。检查字体与视觉层级一致、单层面板、视频收起不留高空白、触控可用、无整页横向滚动。随后各实验录下「操作前 → 动效过程中 → 操作后」三帧或短录屏，确认动效既可见又与真实数据变化一致。旧版和线上状态分别记录。
