# 接口资产梳理 Skill

对**单个接口/服务方法**做全面资产梳理，输出结构化文档，支持迁移、重构、领域拆分或代码审查。

## 何时使用

- 用户要求对某接口做「迁移梳理」「校验与远程调用梳理」「把涉及到的…都确认清楚」
- 用户要求列出：调用链、对外服务、数据库对象、内部对象、技术依赖、校验规则、远程调用
- 目标接口一般为：门面实现类中的某个方法（如 `XxxServiceImpl.yyyMethod`）

## 约束：必须明确目标方法

- 使用方**必须**指定要梳理的**具体方法**，格式：`实现类全限定名#方法名`
- 示例：`ManDaoAccountBookOptService#manDaoAccountBookEdit`
- **不得**笼统说「某接口」「整个 Service」；若用户未写方法名，应追问

## 产出物（固定顺序）

输出为**一份 Markdown 文档**，路径建议 `docs/<接口简短名>-inventory.md` 或 `docs/<接口简短名>-analysis.md`；若用户指定路径则按用户指定。

| 序号 | 章节 | 必须包含 |
|------|------|----------|
| 1 | 入口与入参 | 类#方法名，入参 DTO 及主要字段 |
| 2 | 调用流程（总览） | 入口到返回的步骤，分「总览/分支/主流程」 |
| 3 | 对外服务/远程调用 | 表格：类型、组件/配置、用途、触发条件 |
| 4 | 校验规则 | 表格：顺序、校验项、执行位置、说明 |
| 5 | 数据库对象 | 表格：表名、Schema、读写操作、调用链 |
| 6 | 内部对象 | DTO/BO/工具/Service/Biz/Manager 分类 |
| 7 | 技术依赖 | 幂等、Redis锁、Apollo配置、缓存、魔法值 |
| 8 | 远程调用细化 | 每个会发起远程的检查点的触发条件、请求/响应字段 |

## 执行步骤（按顺序）

1. **确认目标方法**：若用户未给出 `类#方法名`，先追问
2. **定位入口与入参**：从门面找到实现类及该方法，确认入参 DTO
3. **追踪调用链**：从该方法往下追踪所有调用，记录 类#方法、条件
4. **梳理调用流程**：用「总览 + 分支 + 主流程」写出
5. **列对外服务/远程调用**：所有跨进程/跨系统调用
6. **整理校验规则表**：按执行顺序列出
7. **梳理数据库对象**：写操作、读操作、DAO/Mapper
8. **列内部对象**：Facade、BO/DO、工具类、Service/Biz/Manager
9. **技术依赖**：幂等键、Redis锁Key、Apollo配置、缓存、魔法值
10. **远程调用细化**：每个远程调用的检查入口、触发条件、请求/响应字段
11. **落盘**：按产出物章节顺序写入 Markdown

## 执行约定

- 以**代码与配置为准**：通过 grep、语义搜索、读实现类与依赖类完成梳理，不臆造
- 只梳理**该接口一条调用链**上的内容
- 文档用中文；类名、表名、配置 key、枚举名与代码一致
