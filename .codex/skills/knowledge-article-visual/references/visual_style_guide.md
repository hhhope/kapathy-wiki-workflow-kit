# Visual Style Guide

## Target Look

Hand-drawn Chinese knowledge-card infographic, similar to a warm classroom sketchnote:

- Cream paper background
- Marker / crayon / colored-pencil strokes
- Big hand-lettered black Chinese title
- Orange/blue/green/purple keyword highlights
- Rounded cards
- Doodle arrows
- Stars, tape, underlines, squiggles
- Bottom takeaway banner

## Color System

- Blue: step 1 / trigger / goal
- Orange: step 2 / review / problem finding
- Green: step 3 / packaging / resource / SOP
- Purple: step 4 / testing / validation
- Warm yellow: ribbons, bottom banner, highlights
- Black/dark brown: main handwriting and arrows

## Typography Guidance

Prefer direct image-generation handwriting for visual beauty.
But for production-grade accuracy, add Chinese text afterward using a readable handwritten-style Chinese font.

The image should not contain:

- tiny text
- long paragraphs
- text behind icons
- text squeezed into badges

## Layout Grammar

A good slide usually has:

1. Big title
2. Subtitle
3. Main modular body
4. Icons inside each module
5. Flow arrows or comparison structure
6. Bottom golden sentence

## Consistency Rule

In a five-image series, Slide 1 should be the style anchor. Later slides should reference Slide 1 to maintain unified style.
