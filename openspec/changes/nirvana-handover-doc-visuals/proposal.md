## Why

The existing Nirvana handover document already explains risks, unfinished items, drift, and acceptance status, but it is still missing two takeover-critical views:

- a milestone-oriented visual summary that shows baseline nodes against current progress drift
- a clear project team member list so the incoming account owner can identify who to align with

Without these additions, the document remains text-heavy and leaves the incoming owner to reconstruct milestone status and stakeholder coverage manually.

## What Changes

- Add a milestone-progress drift visual section to the Nirvana handover document.
- Add a project team member section sourced from the project staffing spreadsheet.
- Update the local markdown draft and synchronize the same content to the published Feishu document.

None.

### Modified Capabilities

- `nirvana-handover-doc`: The handover document gains milestone drift visualization and explicit project team member coverage.
