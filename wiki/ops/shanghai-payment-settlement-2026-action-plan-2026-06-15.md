# 2026 上海支付结算重点工作行动拆解

## 来源

- 上游材料：上海银发〔2026〕100 号《2026 年上海市支付结算重点工作》
- 已整理来源页：[2026 年上海市支付结算重点工作材料整理](../sources/shanghai-payment-settlement-priorities-2026-05-21.md)
- 本页用途：把 16 项监管要求转成内部可开展事项，供部门负责人分派、拉齐和跟踪。

## 当前判断

这份文件不是单纯宣贯材料，重点是监管穿透、备付金安全、非法支付整治、收单和预付卡全链条、非现场监管系统、投诉处置、反诈资金链治理、系统应急和数据报送。内部不宜按 16 条平均铺开，建议先压成 6 条主线推进。

## 建议优先开展的 6 条主线

| 优先级 | 主线 | 牵头建议 | 要开展的事 | 近期交付物 |
|---|---|---|---|---|
| P0 | 监管自查和整改台账 | 合规 / 风控 | 按 16 项要求建立自查表，区分已满足、需补制度、需补系统、需业务整改、需报送确认。 | `2026 支付结算重点工作自查台账` |
| P0 | 备付金和结算资金安全专项 | 财务 / 清算 / 账户 / 合规 | 核对备付金账户、待结算资金、商户结算账户、虚拟账户、资金沉淀、调账和异常出入金。重点排查挪用、占用、账实不符、非同名结算、异常留存。 | `备付金与待结算资金风险排查报告` |
| P0 | 非法支付、涉赌涉诈资金链治理 | 风控 / 反诈 / 商户运营 / 技术 | 对无证支付、虚假商户、涉赌涉诈、非法金融活动、异常账户和可疑交易建立名单、规则、人工复核、警银协作、线索移送流程。 | `资金链治理规则清单与处置闭环` |
| P1 | 收单和预付卡全链条治理 | 收单业务 / 商户管理 / 风控 / 技术 | 核查商户实名、终端、二维码、交易位置、结算账户、同名结算、预付卡业务数据和高风险商户。把入网、变更、交易、结算、退出串成闭环。 | `收单全链路合规检查表` |
| P1 | 非现场监管系统和数据报送准备 | 数据 / 技术 / 合规 | 对接非现场监管系统，确认接口、字段、频率、可信数据区、SFTP/证书、联调、生产测试、验收、报送异常回执。 | `非现场报送数据口径和联调计划` |
| P1 | 投诉、应急和支付便利性服务改进 | 客服 / 运营 / 技术 / 合规 | 建投诉专项台账，复盘高频投诉；补系统应急预案、演练、疑义信息处置；梳理外卡、现金、老年人、农村、小微等便利性场景。 | `投诉压降与应急演练计划` |

## 可以马上分派的行动项

| 序号 | 行动项 | 参与部门 | 完成口径 |
|---|---|---|---|
| 1 | 组织一次文件精读会，逐条解释 16 项要求和公司现状差距。 | 合规牵头，各业务负责人参加 | 会后形成差距清单，不只留会议纪要。 |
| 2 | 建立监管要求到内部责任人的映射表。 | 合规 / PMO | 每条要求都有牵头部门、配合部门、交付物、截止时间。 |
| 3 | 启动备付金、待结算资金、商户结算账户专项核对。 | 财务 / 清算 / 账户 / 数据 | 能拿出账户清单、余额核对、异常清单和整改计划。 |
| 4 | 启动收单商户、终端、二维码、结算账户一致性排查。 | 收单 / 商户运营 / 风控 / 技术 | 对不一致、非同名、异常位置、异常交易形成处置闭环。 |
| 5 | 把涉赌涉诈治理从模型告警扩展到业务闭环。 | 风控 / 反诈 / 客服 / 运营 | 有规则、有人工复核、有处置记录、有外部协作和宣传材料。 |
| 6 | 梳理非现场监管系统报送准备情况。 | 数据 / 技术 / 合规 | 字段口径、数据来源、报送链路、联调计划和责任人明确。 |
| 7 | 建投诉高发问题专项。 | 客服 / 运营 / 产品 / 合规 | 对投诉量、重复投诉、监管投诉、根因整改进行周跟踪。 |
| 8 | 复盘支付清算系统和央行账户相关应急预案。 | 技术 / 清算 / 财务 | 至少完成预案更新、演练计划、证书和权限检查。 |
| 9 | 梳理支付便利性和普惠支付场景。 | 运营 / 产品 / 商户侧 | 明确外卡、现金、老年人、农村、小微、离境退税等场景是否涉及公司。 |
| 10 | 准备一份支付领域调研选题。 | 合规 / 战略 / 业务 | 形成可报送的研究主题，优先围绕反诈、收单治理、普惠支付或数据报送。 |

## 内部推进节奏

| 时间 | 建议动作 |
|---|---|
| 第 1 周 | 文件宣贯、责任映射、自查台账建模、P0 专项启动。 |
| 第 2-3 周 | 完成备付金、收单、反诈、非现场数据口径第一轮排查，形成问题清单。 |
| 第 4 周 | 对 P0 问题出整改计划，明确系统改造、制度补充、报送沟通和人员培训。 |
| 月度 | 向管理层同步整改进度、监管沟通事项、重大风险和逾期项。 |
| 季度 | 做一次投诉、应急、数据报送、支付便利性和普惠服务复盘。 |

## 需要负责人确认的问题

- 公司是否经营预付卡业务；如不经营，也要形成“不适用说明”和边界依据。
- 跨境业务是否涉及境内商户拓展、收款指令发起或跨境电商收款链路。
- 非现场监管系统当前处于字段确认、联调、生产测试、验收还是常态报送阶段。
- 投诉量是否属于监管关注的高投诉机构；若是，需要成立专项专班。
- 支付便利性、离境退税、普惠农村和适老化服务中，哪些是公司真实业务场景，哪些只需说明不适用。

## 输出边界

本页是内部行动拆解，不是法律意见，也不是最终合规结论。涉及监管报送、处罚风险、业务退出、跨境边界、备付金处置等事项，需要合规、法务和责任部门确认后再对外或对监管提交。
