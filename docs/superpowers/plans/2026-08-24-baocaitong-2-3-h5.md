# 宝财通 2.0 → 3.0 联合评审 H5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一份基于两张方案截图、可离线浏览、可编辑、可在桌面和手机评审的宝财通 2.0 → 3.0 H5。

**Architecture:** 先把临时截图和业务事实沉淀为可追踪的 `wiki/sources` 记录，再以一个 UTF-8 JSON 作为页面事实源，由 Python 标准库构建器生成静态 HTML。CSS、交互脚本和内容数据分离；生成结果不依赖 CDN、远程接口或运行时服务，禁用 JavaScript 时仍保留完整线性内容。

**Tech Stack:** HTML5、CSS3、原生 JavaScript、Python 3 标准库、`unittest`。

**Spec:** `docs/superpowers/specs/2026-08-24-baocaitong-2-3-h5-design.md`

## Global Constraints

- 面向产品、研发、测试和资金链路评审人员；主线固定为“现状 -> 方案演进 -> 推荐方案 -> 改造范围 -> 风险与待确认 -> 评审结论”。
- 3.0 是推荐方向，2.0 是对照；不把推测性收益写成已验证结论。
- 无法可靠辨认的原文必须标记 `待原文确认`，不得猜测补齐。
- 所有资源必须仓库本地化；不得使用 CDN、在线字体、远程接口、凭据、私有 URL 或生产标识。
- 核心流程必须使用确定性 HTML/CSS/SVG 重绘，不把低清截图作为正文主视觉。
- JavaScript 仅做渐进增强；禁用脚本时全部核心内容和两套流程仍可阅读。
- 桌面端支持对照，移动端转为纵向卡片；不得用缩小字体规避布局问题。
- 不同步飞书、不发布、不写入任何外部系统。
- 实施前必须存在一个任务清晰的活动 OpenSpec change；本计划本身不授权实施。

from __future__ import annotations

import html
import json
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
CONTENT_PATH = ROOT / "wiki/reports/assets/baocaitong-2-3-review-h5/content.json"
OUTPUT_PATH = ROOT / "wiki/reports/baocaitong-2-3-review-h5.html"


def load_content(path: Path = CONTENT_PATH) -> dict:
    return json.loads(path.read_text(encoding="utf-8"))


def esc(value: object) -> str:
    return html.escape(str(value), quote=True)


def render_report(content: dict) -> str:
    sections = render_all_sections(content)
    return f'''<!doctype html>
<html lang="zh-CN"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>{esc(content["title"])}</title>
<link rel="stylesheet" href="assets/baocaitong-2-3-review-h5/styles.css">
</head><body><div class="progress" aria-hidden="true"></div>
{render_navigation(content)}<main>{sections}</main>
<script src="assets/baocaitong-2-3-review-h5/app.js"></script>
</body></html>'''


def main() -> int:
    OUTPUT_PATH.write_text(render_report(load_content()), encoding="utf-8")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

```javascript
function setCompareMode(mode) {
  document.querySelectorAll("[data-compare-mode]").forEach((button) => {
    const active = button.dataset.compareMode === mode;
    button.setAttribute("aria-pressed", String(active));
  });
  document.querySelectorAll("[data-version-panel]").forEach((panel) => {
    panel.hidden = mode !== "compare" && panel.dataset.versionPanel !== mode;
  });
  document.documentElement.dataset.compareMode = mode;
}

function setOwnerFilter(owner) {
  document.querySelectorAll("[data-owner-filter]").forEach((button) => {
    button.setAttribute(
      "aria-pressed",
      String(button.dataset.ownerFilter === owner),
    );
  });
  document.querySelectorAll("[data-question-owner]").forEach((card) => {
    card.hidden = owner !== "all" && card.dataset.questionOwner !== owner;
  });
}
```
