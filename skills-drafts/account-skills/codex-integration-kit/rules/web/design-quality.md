# Web Design Quality

## Visual Direction

- The preferred visual direction is high whitespace, clear hierarchy, light neutral surfaces, and blue accents, similar to Claude product UI.
- Do not default to dark mode, yellow-heavy palettes, gray-blue heavy backgrounds, or stacked admin-template layouts.
- Do not add another frontend UI framework to compensate for weak design decisions.

## Must Avoid

- Multiple button size/radius/spacing/priority systems on the same page
- Default card grids with uniform padding and weak information hierarchy
- Metric cards or charts that render shells without real data binding
- Long explanatory copy that crowds the main interface and hides the action model

## Must Do

- Use type scale, whitespace, surfaces, and grouping to create clear hierarchy.
- Keep hover/focus/active/loading/disabled states consistent within one button language.
- Charts, metric cards, risk lists, and batch lists should share one dashboard visual baseline.
- The home page should prioritize engineering-efficiency views, while system health remains a secondary trust/status section.
