# Agent-Task 文档格式参考（reference）

生成 agent-task 下 4 个文档时**必须严格按本 reference 的格式与结构**，避免下次格式漂移。

---

## 路径与命名（项目根下）

- 根目录：`agent-task/`（相对当前项目根）
- 分支+作者目录：`agent-task/{分支名}/{作者}/`，分支名中的 `/` 改为 `-`（如 `component/2025-03-09-exception` → `component-2025-03-09-exception`）
- 文件名：`YYYY-MM-DD-role-task.md`、`YYYY-MM-DD-collaboration-flow.md`、`YYYY-MM-DD-confirm-and-edit.md`、`YYYY-MM-DD-progress.md`
- **时间格式**：所有“日期”“最后更新”“完成时间”**必须**使用 `YYYY-MM-DD HH:mm:ss`（例如 `2025-03-09 14:32:05`），不得只写日期。

---

## 1. role-task.md 模板（结构不可删减）

```markdown
# Role & Task：{任务标题，如「异常处理组件开发」}

**日期**: YYYY-MM-DD  
**分支**: {分支名，如 component/2025-03-09-exception}  
**作者**: {作者}  
**目标**: {一句话目标}

---

## 一、角色与职责

| 角色 | 职责 |
|------|------|
| **您** | 确认协作流程、确认/修改 `confirm-and-edit.md` 中的关键信息、按需查看 `progress.md` 跟踪进度、中断后提供进度信息以恢复 |
| **Agent** | {按具体 skill 或任务说明}；维护 `progress.md`；关键决策前写入 `confirm-and-edit.md` 待您确认 |

---

## 二、目标与范围

- **目标**：{详细目标}
- **范围**：
  - {范围要点 1}
  - {范围要点 2}

---

## 三、任务列表（将同步到 progress.md）

| ID | 任务 | 依赖 | 状态 |
|----|------|------|------|
| T1 | {任务描述} | - | 待确认 |
| T2 | {任务描述} | T1 | 待确认 |
| T3 | … | T2 | 未开始 |

（状态仅：待确认 / 未开始 / 进行中 / 已完成）

---

## 四、产出物索引（本分支+作者目录下）

- 协作流程：`agent-task/{分支名}/{作者}/YYYY-MM-DD-collaboration-flow.md`
- 需您确认/可编辑：`agent-task/{分支名}/{作者}/YYYY-MM-DD-confirm-and-edit.md`
- 进度跟踪：`agent-task/{分支名}/{作者}/YYYY-MM-DD-progress.md`

---

**说明**：执行过程中会约每 1 分钟或每子步骤更新 `progress.md`，便于您随时跟踪和防止中断后丢失上下文。
```

## 2. collaboration-flow.md 模板（结构不可删减）

```markdown
# 协作流程（请您确认）

**日期**: YYYY-MM-DD  
**分支**: {分支名}  
**作者**: {作者}  
**状态**: 待您确认

---

## 一、产出物位置约定

| 类型 | 路径规则 | 说明 |
|------|----------|------|
| 按分支+作者归档 | `agent-task/{分支名}/{作者}/` | 如 `component-2025-03-09-exception/peng_yan/` |
| Role & Task | 同上目录下 `YYYY-MM-DD-role-task.md` | 当日任务定义与角色分工 |
| 协作流程 | 同上目录下 `YYYY-MM-DD-collaboration-flow.md` | 本文档，流程确认后您可签字/打勾 |
| 需确认/可修改 | 同上目录下 `YYYY-MM-DD-confirm-and-edit.md` | 需您确认或可编辑的项 |
| 进度跟踪 | 同上目录下 `YYYY-MM-DD-progress.md` | 当前任务、未完成任务、完成项，便于随时查看与防中断 |

---

## 二、协作流程（请逐项确认或修改）

1. **任务澄清**
   - Agent 根据您的需求，在 `role-task` 中写出：目标、范围、角色、任务列表。
   - 需您确认或可改的项写入 `confirm-and-edit.md`，您修改后 Agent 按最终版执行。

2. **执行与进度**
   - Agent 按任务列表执行，并**至少每 1 分钟**（或每个子步骤结束时）更新 `progress.md`：
     - 当前正在做的任务
     - 未完成任务列表
     - 已完成任务列表
   - 这样即使对话中断，您或新会话可通过 `progress.md` 恢复上下文。

3. **中断与恢复**
   - 若执行中断：您打开当前分支+作者目录下的 `progress.md`，把「当前任务」和「未完成任务」复制给 Agent，即可继续。
   - Agent 在新会话中会先读取当日的 `role-task`、`progress`、`confirm-and-edit`，再继续执行。

4. **确认节点**
   - 关键决策（如分支名、模块名、表名、包名等）先写入 `confirm-and-edit.md`，您确认或修改后再实施。
   - 您可在 `confirm-and-edit.md` 中直接改写内容，并回复「已按 confirm-and-edit 修改，请继续」。

---

## 三、请您确认

请在下表打勾或注明修改意见，确认后 Agent 将严格按此流程执行。

| 序号 | 条款 | 您的确认 |
|------|------|----------|
| 1 | 产出物按分支+作者放在 `agent-task/{分支}/{作者}/`，且文件名带日期 `YYYY-MM-DD` | ☐ 同意 / ☐ 需修改：_____ |
| 2 | 需我确认的信息放在 `confirm-and-edit.md`，我可直接编辑该文件 | ☐ 同意 / ☐ 需修改：_____ |
| 3 | 进度在 `progress.md` 中维护，约每 1 分钟或每子步骤更新，防止中断丢上下文 | ☐ 同意 / ☐ 需修改：_____ |
| 4 | 中断恢复：我提供当日 `progress.md` 中的当前任务与未完成任务即可继续 | ☐ 同意 / ☐ 需修改：_____ |

**您的整体意见**（可选）：  
___________________________________________________________

确认后请回复：「协作流程已确认」或具体修改意见，我再按此流程推进。
```

## 3. confirm-and-edit.md 模板（结构可依任务增删节，但表与标题层级保持一致）

```markdown
# 需您确认 / 可修改项

**日期**: YYYY-MM-DD  
**分支**: {分支名}  
**作者**: {作者}  
**说明**：以下内容请您直接在本文件中修改或打勾确认，Agent 将按您最终版本执行。

---

## 1. Git 分支名

- 建议：`{建议分支名}`
- 您的选择（可直接改写下面一行）：
  ```
  {分支名}
  ```

---

## 2. {与任务相关的确认项标题}

- {说明与选项}
- 您的选择（可改写）：_____

---

## 3. …（按任务需要增加章节）

---

**您完成修改后**，请回复：「已按 confirm-and-edit 修改，请继续」或指出要改的任务项，Agent 将按此文件继续执行。
```

## 4. progress.md 模板（结构不可删减，时间必须到时分秒）

```markdown
# 进度跟踪

**日期**: YYYY-MM-DD  
**分支**: {分支名}  
**作者**: {作者}  
**最后更新**: YYYY-MM-DD HH:mm:ss

---

## 当前正在做的任务

- **T?**：{具体描述，或「无（…）」}

---

## 未完成任务

| ID | 任务 | 状态 |
|----|------|------|
| T? | {任务描述} | 未开始 / 进行中 |

（无未完成任务时保留表头，表体可写一行：`| - | （无） | - |`）

---

## 已完成任务

| ID | 任务 | 完成时间 |
|----|------|----------|
| T? | {任务描述} | YYYY-MM-DD HH:mm:ss |

（完成时间**必须**为 `YYYY-MM-DD HH:mm:ss`，不得只写日期）

---

## 中断恢复说明

若对话中断，请把本文件中「当前正在做的任务」和「未完成任务」两节内容复制给 Agent，并说明「从 progress 继续」，Agent 将据此恢复上下文并继续执行。  
本任务产出目录：`agent-task/{分支名}/{作者}/`。

（此处可追加本次任务特有的说明，如包名修正、产出物路径等。）
```

---

## 格式自检清单

- [ ] 四个文件均在**项目根下的** `agent-task/{分支名}/{作者}/` 中，路径为项目内相对路径
- [ ] 文件名均为 `YYYY-MM-DD-{role-task|collaboration-flow|confirm-and-edit|progress}.md`
- [ ] progress.md 的「最后更新」与「已完成任务」的完成时间均为 `YYYY-MM-DD HH:mm:ss`
- [ ] role-task 与 progress 中的任务 ID（T1、T2…）与状态一致
- [ ] 产出物索引中的路径与当前分支名、作者、日期一致
- [ ] 表格使用 Markdown 表格语法，表头与分隔行完整
