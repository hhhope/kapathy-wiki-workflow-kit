# Output Contract

Use this reference when producing L1/L2/L3 learning output.

## L1 Minimum Output

- source kind;
- what was learned;
- reusable point;
- non-transfer or non-promotion boundary.

## L2 Required YAML Fields

```yaml
learning_level: L2
learning_type: Technical
methods_used: []
input_inventory: []
evidence_matrix: []
value_judgment: ""
proof_boundary: ""
```

## L3 Required YAML Fields

```yaml
learning_level: L3
learning_type: Company Case
methods_used: []
input_inventory: []
research_reconstruction_model: {}
evidence_matrix: []
value_judgment: ""
proof_boundary: ""
output_transformation_plan: {}
```
