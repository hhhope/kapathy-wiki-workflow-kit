# Web Design Quality

## Visual Direction

- Choose one clear visual direction that matches the existing product, then enforce consistent typography, spacing, surfaces, and interaction states.
- Avoid generic admin-template layouts, weak hierarchy, and mixing multiple button/card styles on one page.
- Do not add a new UI framework to compensate for poor layout or component decisions unless the user explicitly approves.

## Must Avoid

- Mixed button size/radius/priority systems on one page
- Uniform card grids with no information hierarchy
- Charts or metric shells that are not backed by real data
- Long explanatory copy that hides the primary action model

## Must Do

- Use type scale, whitespace, grouping, and visual contrast to make the page scan quickly.
- Keep hover/focus/active/loading/disabled states consistent within one component language.
- Verify the real page on desktop and mobile, not only static code structure.
