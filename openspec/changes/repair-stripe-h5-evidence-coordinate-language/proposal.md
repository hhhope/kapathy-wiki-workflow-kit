# Repair Stripe H5 Evidence Coordinate Language

## Why

The rewritten Stripe H5 still contains visible headings that read like
conversation prompts or production notes rather than a unified research report
system. The user rejected headings such as:

- `Stripe 是否已经接近系统级入口？`
- `三维时间轴：时间 x 证据维度 x 证明任务`
- `词条密度：技术、商业、金融、风险四类信号`
- `并购不是大事列表：它们补的是能力缺口`

The next repair must unify the page around one report grammar: evidence
coordinates.

## What Changes

- Rename reader-visible sections into a consistent `证据坐标` system.
- Remove conversational or rhetorical headings.
- Make the signal cloud clickable so terms filter or open evidence meaning.
- Surface the 1000-source queue as a grouped evidence inventory, not as 22
  isolated proof nodes.
- Keep the H5 an internal draft and preserve evidence boundaries.

## Non-Goals

- No Feishu sync or publication.
- No new source crawling or 1000-source reading claim.
- No market-share overclaim.
- No unrelated redesign outside the Stripe H5.

## Impact

- Updates one H5 draft.
- Updates the gate review and verification evidence.
- Adds one follow-up OpenSpec trace for the post-completion correction.
