# 涅槃一期领导汇报简版

## 一、当前判断

| 项目 | 结论 |
| --- | --- |
| 汇报范围 | 直销模式一期 |
| 汇报时间点 | 截至 `2026-04-15` |
| 原业务里程碑 | `2026-06-30`，当前已偏离 |
| 当前功能基线 | `协议支付退款测试完成 2026-07-10`，`协议支付基础能力上线 2026-07-23` |
| 当前总体判断 | 直销模式一期已具备产品上架、统一网关、收单能力和账户承接基础；BM 对账回单、分账、代销层级能力不纳入当前一期承诺 |

## 二、一期承诺范围

| 主题 | 当前口径 |
| --- | --- |
| 一期主线 | 产品上架、统一网关、收单能力、账户承接、基础退款 |
| 当前主线 | 当前 7 月窗口内以协议支付为主的收单能力 |
| 不纳入一期承诺 | BM 对账回单、分账、代销层级能力、完整收益计费能力 |

## 三、关键节点

| 节点 | 时间 | 当前说明 |
| --- | --- | --- |
| 产品上架节奏 | `4 月 / 5 月 / 6 月` | 当前业务节奏为 `4 月上架收单能力`、`5 月上架宝财通`、`6 月上架慧收钱` |
| 退款测试完成 | `2026-07-10` | 当前基础退款完成窗口 |
| 基础上线窗口 | `2026-07-23` | 当前收单能力基础上线窗口 |

## 四、当前约束

| 约束项 | 当前表现 | 影响 |
| --- | --- | --- |
| 统一网关未闭环 | `Nacos`、IP 白名单、压测、产品集成、API 迁移仍在排期 | 收单能力不能按统一入口已完全就绪表达 |
| 基础退款后置 | 当前未开始，完成点是 `2026-07-10` | 直接影响 `2026-07-23` 上线窗口 |
| BM 范围未成包 | 对账下载和回单下载未形成一期交付包 | 当前只能讲基础查询和退款入口方向 |
| 分账范围未确认 | 当前均未开始，边界也未确认 | 当前不能把支持分账作为一期对客口径 |

## 五、现在能讲什么

| 对客主题 | 当前能讲什么 | 当前不能讲什么 |
| --- | --- | --- |
| 产品上架 | 能讲直销模式下的产品上架节奏和开通配置基础 | 不能讲代销层级开通能力 |
| 收单能力 | 能讲协议支付为主的直销收单能力 | 不能讲代销多主体收单能力 |
| 统一网关 | 能讲统一接入方向和基础能力已经建立 | 不能讲全部迁移和压测闭环 |
| 账户承接 | 能讲账户底座和统一动账 | 不能讲完整结算、冻结、查询兼容闭环 |
| 基础退款 | 能讲基础退款已纳入一期 | 不能讲退款治理和 BM 退款运营已经具备 |

## 六、资源诉求

| 诉求 | 为什么要 | 不处理会怎样 |
| --- | --- | --- |
| 补 1 个收单能力研发位 | 把结果通知、补单、补发清算、订单查询从分账拉扯中保护出来 | 当前主线继续被动延后 |
| 补 1 个 BM 研发位 | 把查询、对账、回单、退款入口独立成包 | BM 永远挂在主线后面 |
| 补 1 个测试窗口 | 保障收单能力和基础退款回归 | `2026-07-10` 到 `2026-07-23` 的缓冲会被直接吃掉 |

## 七、待拍板事项

| 事项 | 截止时间建议 | 当前建议 |
| --- | --- | --- |
| BM 对账下载、BM 回单下载是否进入一期 | `2026-04-18` | 明确不进入，或单独成包 |
| 分账是否进入一期 | `2026-04-18` | 当前建议不进入一期对客承诺 |
| 分账退款按哪套方案走 | `2026-04-18` | 先形成唯一口径，再决定是否排期 |
| 失败计费是否进入一期 | `2026-04-18` | 若无稳定承接，不纳入一期 |

## 八、汇报口径

- 当前汇报只讲直销模式一期。
- 当前不继续扩需求，重点是锁定一期范围，保住 `2026-07-23` 的基础上线窗口。
- 当前不把 BM 对账回单、分账、代销层级能力作为一期已具备能力表达。
