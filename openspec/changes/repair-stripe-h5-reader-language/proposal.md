# Repair Stripe H5 Reader Language

## Why

The Stripe H5 still exposes process language and conversational framing in the
reader-facing page. The issue is not only section titles; visible copy,
interactive labels, and signal details still use phrases such as "not",
"this section", "proof", "lane", "boundary", "queue", and "draft" as if the
reader were reviewing the production process.

## What Changes

- Rewrite visible H5 copy into consistent report language.
- Remove process labels from reader-facing controls and detail panels.
- Keep evidence caveats in a compact citation note, not as repeated negative
  prose.
- Preserve current structure, sources, and interactions.

## Non-Goals

- No new sources.
- No new visual structure.
- No publication or Feishu sync.

## Impact

- Updates the Stripe H5 page and gate review.
- Keeps the change scoped to reader-facing language quality.
