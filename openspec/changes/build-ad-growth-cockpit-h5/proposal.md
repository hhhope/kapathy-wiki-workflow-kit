# Build Ad Growth Cockpit H5

## Why

The repository needs a customer-facing H5 prototype that turns
`inbox/ad-desgin.md` from an internal advertising system design into a readable
demo for advertisers and customer-side decision makers.

## What Changes

- Add a standalone static H5 prototype at `wiki/reports/ad-growth-cockpit-h5.html`.
- Add a focused contract test covering required sections, anchors, interaction
  hooks, and customer-facing content mapping.
- Add a repo-visible public-output gate review record for the prototype.

## Non-Goals

- No backend, login, media-platform API, or real campaign data.
- No Feishu sync or publication claim.
- No change to repository runtime behavior, skill routing, or governance rules.

## Impact

- Adds one reader-facing prototype artifact.
- Adds one test file and one wiki ops review note tied to this prototype.
