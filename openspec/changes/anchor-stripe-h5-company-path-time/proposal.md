# Anchor Stripe H5 Company Path In Time

## Why

The current Stripe H5 still separates company path and timeline too much:

- `公司路径：五次位置迁移` describes five positions but does not show when each
  transition happened.
- The path cards say what Stripe did, but not clearly enough how strategic
  choices accumulated into today's position.
- The timeline heading `关键转折：Stripe 每次把自己嵌到更深的位置` is still too
  abstract for a business-analysis report.
- The support copy below that heading remained from the previous version because
  the prior repair preserved a sentence the agent incorrectly judged as
  acceptable.

## What Changes

- Rename the company path section to carry the date range.
- Add visible year ranges to each path stage.
- Rewrite each path stage around `战略选择 -> 能力沉淀 -> 成就位置`.
- Rename the timeline section with a more concrete business-analysis claim.
- Replace the abstract support paragraph with specific stage logic.
- Update gate-review evidence with the cause and verification.

## Non-Goals

- No new source collection.
- No full redesign of the H5.
- No changes to unrelated sections unless needed for consistency.

## Impact

This is a focused correction to the Stripe H5's company-path and timeline
framing.
