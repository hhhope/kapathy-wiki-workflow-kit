# Rewrite Stripe AI Company Evolution H5

## Why

The current Stripe H5 no longer explains the research argument clearly. It has
source-heavy sections such as market calculation panels, mixed company /
technical timelines, and AI transaction blocks that do not tell the reader what
each visual proves.

The user selected a BVP `State of the Cloud 2024`-style direction: one strong
theme, trend cards, notable data points, implications, and a central
three-dimensional timeline. The H5 should now answer a sharper question:

> Stripe 如何理解 AI 时代的交易变化，它如何重新定位自己，我们能从它的路径中学到什么？

## What Changes

- Rewrite `wiki/reports/stripe-ai-company-evolution-h5.html` into a
  BVP-style trend report.
- Use a three-dimensional timeline organized by time, evidence lane, and proof
  tag.
- Turn market position into a supporting visual inside the timeline narrative,
  not a standalone calculation panel.
- Map acquisitions to capability gaps.
- Show AI transaction change as a chain from demand discovery to machine
  payment and risk shift.
- Update the report gate review with reader intent, selected reference shape,
  evidence boundaries, verification results, and non-publication status.

## Non-Goals

- No Feishu sync or publication claim.
- No exact audited global market-share claim.
- No claim that all 1000 queued sources have been read.
- No new backend, build system, database, crawler, or live API integration.
- No unrelated H5/report style overhaul outside the Stripe H5.

## Impact

- Replaces one internal reader-facing H5 draft.
- Updates one report-quality gate review artifact.
- Preserves existing source files and source queue as evidence inputs without
  treating the queue itself as the reader-facing story.
