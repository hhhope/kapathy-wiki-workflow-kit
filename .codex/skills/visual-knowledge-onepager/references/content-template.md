# Content Template

Use this template in Step 5 when drafting the Xiaohongshu carousel content.

## Per-image output structure

```markdown
## 图片[X]：[核心主题名称]

**主标题：** [主题名称]选择指南 / [主题名称]避坑攻略
**副标题：** [6-7]大维度全面解析[主题名称]

### 网格区域

**[网格1，4字]** - 品牌/选项类
- 选项A：[名称]：[关键特点 + 数字/参数]
- 选项B：[名称]：[关键特点 + 数字/参数]
- 选项C：[名称]：[关键特点 + 数字/参数]

**[网格2，4字]** - 数值阶梯类
- [数值1]：❌ 不合格 / 不推荐
- [数值2]：✓ 合格 / 可用
- [数值3]：👑 优秀 / 优先

**[网格3，4字]** - 场景对比类
- 场景A：[适用条件 + 具体建议 + 数据]
- 场景B：[适用条件 + 具体建议 + 数据]
- 场景C：[适用条件 + 具体建议 + 数据]

**[网格4，4字]** - 识别技巧类
- 看：[识别方法]
- 测：[验证方法]
- 问：[购买或选择时要确认的问题]

**[网格5，4字]** - 对比/推荐类
- 人群A：[推荐组合]
- 人群B：[推荐组合]
- 人群C：[推荐组合]

**[网格6，4字]** - 黑底避坑类
⚠️ 避坑清单：
- ❌ [错误做法1]：[后果]
- ❌ [错误做法2]：[后果]
- ❌ [错误做法3]：[后果]

**[网格7，4字]** - 速查/总结类
- 一句话结论：[简短结论]
- 快速建议：[最省时间的判断法]
```

## Density rules

- Every image must contain 6-7 grid modules.
- Every module must contribute unique value; do not duplicate points across grids.
- Prefer specific numbers, prices, sizes, specs, weights, percentages, model names, or brand names.
- If hard data is unavailable, use scenario thresholds or decision heuristics instead.
- Keep labels short and rhythmic. Four Chinese characters are preferred for grid names.

## Suggested module patterns

Choose from these when the topic needs variety:

- 品牌选择
- 参数标准
- 场景对比
- 型号分类
- 识别方法
- 搭配建议
- 人群适配
- 快速速查
- 避坑提醒
- 常见误区

## Illustration planning notes

At the end of each image draft, also list:

- 2-4 concrete illustration objects
- 1 warning symbol or contrast icon
- 1-2 filler graphic motifs such as arrows, stars, checkerboards, or diagonal lines
