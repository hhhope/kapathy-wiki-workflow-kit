# Polish Stripe H5 Visual Language

## Why

The latest Stripe H5 repair fixed section structure but still fails visual and
reader-language quality in the first screen and market/path sections:

- the processed-volume line chart looks awkward and overstates precision
- `交易关系` / `信用关系` labels read like dry internal taxonomy
- `公司路径：五次位置迁移` is still a card grid without a clear visual path
- the market-position headline and caveat paragraph sound like an internal
  audit note rather than reader-facing report prose
- the company timeline title and instruction copy use process language such as
  `并读` and `拖动年份看`, which reads like a chat description instead of
  business analysis
- the strategy chapter still uses mechanical labels such as `壁垒读法` instead
  of a reader-facing conclusion
- the AI-era payment section still uses generic AI phrasing and the section
  styling is visually weak
- the original-source quote section uses inconsistent card grammar
- the signal matrix still reads like a decorative word cloud rather than a
  categorized evidence index

## What Changes

- Replace the first-screen processed-volume line with a clearer scale snapshot:
  annual volume blocks, a visible growth arrow, and source-boundary note.
- Rewrite transaction / credit relationship copy into plain Chinese.
- Turn the five-position migration section into a path visual with connected
  stages instead of a flat grid.
- Rewrite market-position heading and caveats into report language while
  preserving source boundaries.
- Rewrite the company timeline heading and intro into a business-analysis
  claim, and improve the section's visual hierarchy.
- Treat `哪些战略造就了 Stripe` as a strategic timeline / compounding chain and
  replace mechanical labels with plain report conclusions.
- Rewrite the AI-era payment section in business language and restyle it as a
  control-point map instead of generic stacked cards.
- Normalize the source-quote section into one card grammar: source id, claim,
  short quote, support, and boundary.
- Replace decorative signal-cloud styling with a categorized signal matrix.
- Refresh screenshots and gate-review evidence.

## Non-Goals

- No new source collection.
- No Feishu sync or public release.
- No broad rewrite of the full H5.
- No changes to unrelated report pages or workflow rules.

## Impact

This is a narrow visual and language polish for one internal H5 draft and its
report gate evidence.
