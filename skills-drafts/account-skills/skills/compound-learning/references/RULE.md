# Rule：经验复利系统完整行为约束

## 五条硬规则

**1. PRD未锁定不执行**
无论PRD来源是你还是Claude，未经确认锁定前不开始执行。
Claude产出PRD时必须主动标出对自己最容易完成的部分，让风险透明。

**2. 执行前必须查库**
收到任务后先读PRD和错题本，标记高风险节点再执行。
查库结果默认静默，只在发现高度相关历史错误时一句话说明。

**3. 执行中不打断**
纠错/追问发生时，pivot到新目标继续执行，内部标记偏差点。
唯一可提问：PRD未覆盖的外部事实缺口，一次问完所有问题。

**4. 复盘是产出的尾部附件，不是独立环节**
任务完成时：产出本体 + PROJECT.md更新，一次交付。
无意外的常规任务只交付产出，不附PROJECT.md。

**5. 错误归因必须走判断链，不能凭感觉定主人**
信息不足且未追问就执行 → Claude的错
信息不足，追问了但补充仍不清晰 → 你的错
信息充足，判断错 → Claude的错
信息充足，判断对但预期改变 → 目标未对齐

---

## 超时/中断处理方案

### Task 工具集成（强制）
- Phase 0 拆分任务 → TaskCreate()
- Phase 1 检查断点 → TaskList()
- Phase 2 执行 → TaskUpdate(status: in_progress) → 完成后 TaskUpdate(status: completed)

### Task 拆分规则
- 单个 Task 预计时间 > 60秒 → 必须拆分
- 每个 Task 必须包含：验收子项 + 优先级(P1/P2/P3) + 预计时间(秒)

### 断点续传流程
1. Phase 1 开始时 TaskList()
2. 找到状态=in_progress/pending 的 Task
3. 从该 Task 继续执行
4. 完成后 TaskUpdate(status: completed)

## 禁止行为

- ❌ PRD未锁定开始执行
- ❌ 执行中途插入复盘或请示
- ❌ 一次经验晋升通用层（需≥2个项目）
- ❌ 输出没有触发条件的错题
- ❌ 输出没有验收标准的学习计划
- ❌ 全量加载经验库
- ❌ Claude产出PRD不暴露自我迎合风险直接执行
- ❌ 把描述不清导致的误解归为Claude的Skill错误注入
