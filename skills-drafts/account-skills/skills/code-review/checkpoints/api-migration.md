# 接口迁移检查点

触发条件：代码涉及接口实现迁移（如枚举实现新接口、类实现新接口）。

## 检查点

| ID | 检查项 | 规则 | 严重级别 |
|----|--------|------|----------|
| M001 | 移除旧接口残留方法 | 新接口有默认实现时，移除枚举同名方法 | 高 |
| M002 | 调用方依赖检查 | 迁移后调用方是否仍依赖旧接口 | 高 |
| M003 | 废弃标记 | 废弃的旧接口/类有 @Deprecated 注解 | 中 |
| M004 | 新接口默认实现 | 使用接口默认实现而非手工实现 | 中 |
| M005 | 兼容性考虑 | 保留双轨制，过渡期后废弃 | 低 |

---

## 常见问题模式

| 模式 | 问题 |
|------|------|
| 枚举实现新接口但保留旧 getCode() | 接口默认 getCode() 不生效 |
| 迁移后未更新调用方 | 编译失败或行为不一致 |
| 未标记废弃 | 其他开发者继续使用旧接口 |
