# One-Page Infographic Template

## Purpose

Compress an article, framework, method, report, or workflow into one dense but
readable visual poster.

## Required Inputs

- Topic
- Audience
- Core argument
- Problem or misconception
- Evidence or examples
- Boundary / warning
- Desired next action

## Generic Structure

- Top title
- Subtitle
- 5 main modules
- 2 support modules
- Bottom golden sentence
- Optional mini flow strip

## Five Main Modules

Use these slots generically. Replace labels with topic-specific wording.

1. `01 核心问题`
   - What misunderstanding, pain, or decision does the reader face?
   - Show the old/default way.

2. `02 为什么重要`
   - Why does this matter now?
   - Contrast old vs new, or weak vs strong approach.

3. `03 本质模型`
   - What is the core structure, metaphor, or operating principle?
   - Show 3-6 building blocks.

4. `04 如何运行`
   - How does the model work in practice?
   - Use a loop, step chain, checklist, or responsibility map.

5. `05 边界与下一步`
   - What should not be overclaimed?
   - What should the reader do next?

## Support Modules

Pick up to two:

- Evidence boundary
- Common mistake
- Role/action mapping
- Metrics to observe
- Source/sample list
- High-risk warning

## Density Rules

- Max 5 main modules.
- Max 4 bullets per module.
- Max 2 auxiliary modules.
- Bottom takeaway must be large enough to read.
- Icons should support text, not replace the argument.
- Do not use hardcoded examples from another domain unless the user provided
  that domain as the source.
