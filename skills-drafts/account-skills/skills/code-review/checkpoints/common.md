# 通用检查点

适用于所有代码评审的 6 个维度。

> [!info] 检查点优先级
> - **高优先级**：C001-C006（正确性、稳定性、安全性）
> - **中优先级**：C007-C010（可测试性、可维护性）
> - **低优先级**：C011-C012（可观测性）

## 检查点

| ID | 维度 | 检查项 | 规则 |
|----|------|--------|------|
| C001 | 正确性 | 业务逻辑正确 | 无明显逻辑错误 |
| C002 | 正确性 | 边界条件处理 | 需处理 null/空/边界值 |
| C003 | 稳定性 | 异常处理 | 有 try-catch 或抛出异常 |
| C004 | 稳定性 | 资源释放 | 有 finally 或 try-with-resources |
| C005 | 安全性 | 敏感数据 | 无硬编码密码/密钥 |
| C006 | 安全性 | SQL注入 | 使用参数化查询 |
| C007 | 可测试性 | 依赖注入 | 依赖通过构造函数注入 |
| C008 | 可测试性 | 方法长度 | 单方法 < 80 行 |
| C009 | 可维护性 | 命名规范 | 变量/方法名有意义 |
| C010 | 可维护性 | 重复代码 | 无明显重复逻辑 |
| C011 | 可观测性 | 日志记录 | 关键操作有日志 |
| C012 | 可观测性 | 异常信息 | 异常包含上下文信息 |

---

## 评分权重

| 维度 | 分值 |
|------|------|
| 正确性/业务逻辑 | 30 |
| 稳定性/异常处理 | 20 |
| 安全性/合规 | 15 |
| 可测试性/验证证据 | 15 |
| 可维护性 | 10 |
| 可观测性 | 10 |
