# Shanghai Payment Skill Reference Share

This package contains the workflow skills and rule references used while
processing `上海银发〔2026〕100 号 2026 年上海市支付结算重点工作`.

It does not contain the business H5 draft itself. It is intended for sharing
the agent workflow, routing gates, visual checks, and verification references.

## Contents

- `skills/material-collaboration-defaults.md`: source-first material processing
  route for inbox attachments and reports.
- `skills/public-report-quality-gate.md`: reader-facing H5/report gate and
  draft/share boundary.
- `skills/wiki-inbox.md`: inbox routing surface used to locate candidate
  source material.
- `skills/interview-deep-reading-board.md`: reference-shape route for the Li
  Xiang style reading-board structure.
- `skills/interview-deep-reading-board-h5-output-shape.md`: H5 output-shape
  reference used for paragraph windows, timeline/map, keyword index, and
  evidence panel.
- `skills/wiki-frontmatter-taxonomy.md`: frontmatter checking route for the
  source note.
- `skills/frontend-visual-governor.md`: visual/layout repair route used when
  the H5 page layout was corrected.
- `skills/verify-before-claiming.md`: final evidence and git-state check before
  completion claims.
- `skills/superpowers-using-superpowers.md`: session-start skill routing
  reference loaded at the beginning.
- `rules/web-design-quality.md`: design-quality rule reference used for layout
  quality checks.

## Boundary

These are reference copies for sharing and review. They are not a new source of
truth and do not modify the original skill or rule files.
