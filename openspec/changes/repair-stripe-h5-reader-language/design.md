# Design: Stripe H5 Reader Language

## Language Standard

Use report-language that states the artifact directly:

- "规模坐标呈现..."
- "时间轴并置..."
- "并购坐标显示..."
- "信号索引汇总..."

Avoid:

- "这一页/这一坐标只回答"
- "不是..."
- "不能证明..."
- "proof / lane / boundary / queue / draft"
- production instructions such as "点击后查看"

Evidence caveats stay in compact labels:

- `口径`
- `来源`
- `未晋级材料`

## Verification

Run a grep for the rejected terms against the reader-facing H5.
